# 赛事记忆卡片 · Demo

触碰奖牌或号码簿(NFC 写入的网址)→ 认领 → 上传照片 / GPX / 成绩 → Agent 整理 → 预览编辑 → 保存导出 → 再次触碰回看。

产品依据:`docs/NFC越野赛事记忆卡片-产品确认稿-v0.2.html`。本仓库只实现其中的「赛后记忆」闭环。

**所有赛事、选手、成绩均为虚构占位。**

> **本仓库不含 `docs/` 目录**(产品确认稿、内部测试数据包)。其中的外部来源 GPX 商用授权未确认、含 AI 合成图,不随公开仓库分发。
> 应用启动时会读取 `docs/demo-fixtures/event.json` 和 `players.json` 作为种子数据,**没有这个目录应用无法启动**。要运行完整 demo,需要自备同结构的数据(赛事配置、选手、成绩截图、GPX、主视觉图)。单元测试在缺少数据时会自动跳过依赖它的用例。

## 运行

```bash
cp .env.example .env.local     # 填 LLM_API_KEY;不填则文案用固定模板,成绩识别关闭,仍可手填
npm install
npm run build && npm run start -- -p 3100     # 或 npm run dev
```

打开 `http://localhost:3100/demo`:演示控制台,显示每名选手的 NFC 入口二维码、认领码、当前状态。真机请用局域网地址访问。

## 控制台

| 功能 | 说明 |
|---|---|
| 二维码 / 入口链接 | 奖牌与号码簿各一枚标签,指向同一份记忆 |
| 认领码 | 独立于号码和网址;正式使用时随号码簿发放 |
| 一键造草稿 / 生成中 / 待确认 | 走真实的素材整理流程,不塞假数据 |
| 注入失败 | 上传、成绩识别、文案模型、生成,四类,用来测试失败恢复 |
| 重置 | 单个选手或全部回到 `docs/demo-fixtures/players.json` 的初始状态 |

初始选手:林小野 DEMO 021(未认领)、陈逐风 DEMO 022(已认领无素材)、许听松 DEMO 023(已保存)。

## 规则落地(来自产品文档)

- **私人内容需认领凭证。** 标签网址只能看到赛事主视觉、赛事名和号码是否已认领;姓名、成绩、照片都要用认领码换来的会话 Cookie。无权限与不存在的选手返回同样的 404。连续输错 5 次锁定 60 秒。
- **成绩不自动标官方。** 识别结果只是预填,用户核对并点保存后才算数,来源记为 手填 / 识别后确认 / 用户编辑。无排名保持空值。
- **参考路线与个人轨迹分开显示。** 参考路线用虚线并标注"非实际行走记录",不计算选手的配速、爬升或用时。
- **文案只依据确认过的事实。** 模型输出要过校验:不含伤病、天气、心情、沿途事件、配速;数字必须与事实一致(含"1小时42分36秒"和中文数字写法)。两次不通过则改用固定模板。
- **姓名、号码、成绩由固定模板绘制,不经过模型。**
- **保存不替换旧版。** 补充素材重新生成得到的是草稿,确认保存后才替换;放弃或失败时旧版保留。
- **缺失字段不造假。** 没有成绩或轨迹时生成简版卡片并隐藏对应字段。

## 测试

```bash
npm test                                  # 单元测试:GPX 解析、文案校验(50 项;缺测试数据时部分用例跳过)
node scripts/e2e-api.mjs http://localhost:3100   # 接口端到端(99 项,需要本地的 docs/demo-fixtures,服务以 DEMO_MODE=1 运行)
```

接口测试会调用真实的大模型(成绩识别和文案)。数据包校验:`python3 scripts/verify-demo-fixtures.py`。

## 已知限制

- **成绩识别只在 3 张合成图上测过**(gpt-4.1-mini,全对)。真实成绩单的准确率未知,所以必须人工核对。
- **文案模型有时不稳定**:偶尔写出取整后的距离等,会被校验拦下并重试,最终回退到固定模板。
- **认领码演示时显示在控制台。** 正式使用需要线下发放,并且要有失效与补发机制。
- **数据存本地 SQLite(`data/`)和磁盘**,没有备份、保存期限和删除入口,这些产品文档里标为待确认。
- **没有做**:真实 NFC 写入与验证(已另行完成)、公开分享、长游记、实时计时、运动平台同步、摄影师图库匹配、赛中监测。
- 内置的 `node:sqlite` 在 Node 22 仍标为实验特性,启动时会打印警告。
- 参考路线来自外部 GPX,商用授权未确认,不得对外发布。
